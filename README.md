# The Forgotten Rooms

An Adventure Game You Didn't Know You Needed !

Started as a dumb little text game I made right after my 42 piscine. You typed stuff, rooms happened, a narrator made fun of you. It was fun to make and honestly pretty funny.

Two years later I'm turning it into a real first-person game. I recycled my mate and I's cub3D project and now you will actually walk through the rooms instead of reading about them. Tables, shelves, locked doors, dark corridors. The whole thing.

Still in C. Still has the narrator. Still makes fun of you.

---

## Build

```bash
make
./forgotten_rooms maps/entrance_hall.cub
```

Requires MinilibX. Linux only.

---

## Controls

| Key | Action |
|-----|--------|
| W / S | Move |
| A / D | Strafe |
| ← → | Look around |
| E | Interact |
| I | Inventory |
| ESC | Quit |
